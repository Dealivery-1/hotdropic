# The Hot Dropic

What's hot right now, dropped to your door. A trend-driven dropshipping store: original meme tees and hoodies (printed on demand by Printful) plus viral gadgets, room glow-ups and more (CJ Dropshipping), picked automatically by a trend scanner and promoted automatically every day.

- **Launch it:** [SETUP.md](SETUP.md) (about 45 minutes, $0/month)
- **Edit it (people and AI agents):** [CLAUDE.md](CLAUDE.md)
- **Owner dashboard:** `/admin` on the live site

Cloudflare Workers + D1 (free plan), Stripe Checkout, vanilla JS, zero npm dependencies. `npm test` runs the test suite.
